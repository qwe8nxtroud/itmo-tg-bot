Коротко о системе: Telegram-бот на aiogram отвечает через YandexGPT (OpenAI-совместимый
API) и хранит историю, настройки, напоминания и аудит в PostgreSQL. В режиме агента он
вызывает инструменты собственного MCP-сервера: погоду (Open-Meteo), расписание и
напоминания. Сервер запускается дочерним процессом по stdio. Бот проверяет каждое решение
модели кодом: имя и аргументы инструмента, лимит вызовов, подтверждение действий
пользователем, подпись владельца, скрытие инъекций в данных и утечек системной инструкции.
